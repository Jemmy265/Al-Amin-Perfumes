# موقع الأمين للعطور

موقع تعريفي بلغة عربية (RTL) لمتجر عطور، بألوان مستوحاة من الشعار (وردي فاتح، أسود، ذهبي).
عند الضغط على "اطلب الآن" في أي منتج، يفتح الموقع واتساب مباشرة برسالة جاهزة تتضمن اسم العطر.

## هيكل الملفات

```
alamin-website/
├── index.html          الصفحة الرئيسية (كل الأقسام)
├── css/style.css        التنسيقات والألوان
├── js/script.js         بيانات المنتجات + روابط واتساب + القوائم
├── assets/               الشعار وأيقونات التبويب
└── README.md
```

## قبل النشر — خطوتان ضروريتان

افتح ملف `js/script.js` وعدّل أعلى الملف:

1. **رقم واتساب حقيقي** — استبدل:
   ```js
   const WHATSAPP_NUMBER = "201000000000";
   ```
   بالرقم الفعلي بالصيغة الدولية بدون علامة `+` وبدون صفر البداية.
   مثال: رقم مصري `01098765432` يصبح `201098765432`.

2. **تعديل قائمة المنتجات** — كل عطر عبارة عن سطر داخل `PRODUCTS`:
   ```js
   { name: "عبق الليل", category: "women", desc: "...", price: 850 },
   ```
   - `category` يجب أن تكون `women` أو `men` أو `oud` (أو أضف تصنيفًا جديدًا وأضف زر فلتر له في `index.html`).
   - أضف أو احذف أسطرًا بحرية — البطاقات والفلاتر وروابط واتساب تُبنى تلقائيًا من هذه القائمة.

أيضًا، في `index.html` استبدل رقم الهاتف التجريبي في قسم "تواصل معنا" (`tel:+201000000000` واسم حساب إنستجرام) ببيانات نشاطك الفعلية.

## رفع الصور الحقيقية للمنتجات (اختياري)

حاليًا تُستخدم رسمة زجاجة عطر بسيطة بدل صور حقيقية (لأنه لم تتوفر صور منتجات). لإضافة صورة حقيقية لكل عطر:

1. ضع الصور داخل مجلد `assets/products/`.
2. في `js/script.js` أضف حقل `image: "assets/products/name.jpg"` لكل منتج.
3. في دالة `renderProducts()` استبدل رسمة الـ SVG بوسم `<img>` يستخدم `p.image`.

## النشر على GitHub Pages

1. أنشئ مستودعًا (repository) جديدًا على GitHub وارفع محتوى هذا المجلد بالكامل (بحيث يكون `index.html` في الجذر الرئيسي للمستودع).
   ```bash
   git init
   git add .
   git commit -m "Initial website"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git push -u origin main
   ```
2. من صفحة المستودع على GitHub: **Settings → Pages**.
3. تحت **Build and deployment**، اختر **Source: Deploy from a branch**.
4. اختر **Branch: main** والمجلد **/ (root)**، ثم اضغط **Save**.
5. بعد دقيقة أو دقيقتين سيكون الموقع متاحًا على:
   `https://USERNAME.github.io/REPO_NAME/`

لا يحتاج المشروع لأي عملية بناء (build) — ملفات HTML/CSS/JS ثابتة وجاهزة للنشر مباشرة.

## اختبار محلي

يمكنك فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي بسيط:
```bash
python3 -m http.server 8000
```
ثم زيارة `http://localhost:8000`.
